# 会议知识库后续优化顺序

1. 跨会议问答：选择会议，逐场校验权限与已确认纪要版本，分别检索并标注来源，隔离会话与精确缓存。
2. 检索与问答评测：选取代表性会议样本，覆盖单会议、追问、跨会议和资料不足场景，记录答案与来源质量、耗时及 Token。
3. 混合检索和重排序：结合关键词与向量召回，比较人名、编号、日期等查询的效果。
4. 决策变化与事项时间线：关联不同会议中同一事项的讨论、决议及状态变化，保留来源供用户核实。
5. 行动项与 OA 同步：用户确认后创建待办，处理权限、幂等、失败重试和同步状态。
6. 会议内容过滤：结合会议目标区分核心讨论和闲聊，通过评测检查重要内容的遗漏。

各阶段先完成可验证的基本流程，再根据评测结果优化。历史会议数据和现有权限规则需要保持兼容。
